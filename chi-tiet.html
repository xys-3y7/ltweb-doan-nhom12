Tóm tắt nội dung và cấu trúc cuốn sách

Cuốn sách "Lập trình Web hiện đại với HTML5, CSS3 và PHP" là tài liệu học tập chính thức cho học phần Thiết kế và Lập trình Web. Sách được biên soạn công phu với phương châm lấy thực hành làm trọng tâm, giúp người học nắm vững kiến trúc ứng dụng web đa tầng từ cơ bản đến nâng cao.

Cấu trúc các chương mục chính:

  1. Chương 1: Tổng quan về Web và Môi trường phát triển: Mô hình Client-Server, giao thức HTTP/HTTPS, cấu hình Apache, PHP và MySQL.
  2. Chương 2: Cấu trúc tài liệu HTML5 ngữ nghĩa: Các thẻ semantic (header, nav, main, article, section, footer), cây tiêu đề h1-h6, biểu mẫu form kiểm tra hợp lệ phía trình duyệt, khả năng tiếp cận (Accessibility - a11y) và tối ưu hóa công cụ tìm kiếm (SEO).
  3. Chương 3: Định kiểu giao diện với CSS3 và Responsive Design: Box model, Flexbox, CSS Grid, Media Queries thích ứng trên máy tính và thiết bị di động.
  4. Chương 4: Lập trình tương tác phía máy khách với JavaScript: Thao tác DOM, xử lý sự kiện, kiểm tra form động và gọi API bất đồng bộ (Fetch/AJAX).
  5. Chương 5: Lập trình phía máy chủ với PHP & MySQL: Xử lý form POST/GET, quản lý phiên làm việc với Session và Cookie, kết nối cơ sở dữ liệu PDO và bảo mật ứng dụng web chống SQL Injection và XSS.
